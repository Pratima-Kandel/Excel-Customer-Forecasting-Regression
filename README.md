# 📊 Customer Arrival Forecasting & Decision Analysis

Statistical analysis combining **multiple linear regression** and **decision tree analysis** to optimize staffing decisions based on daily customer arrival patterns.

## 📊 Regression Analysis Preview

![Regression Analysis](01-regression-analysis.png)

## 🎯 Project Overview

Built statistical models to help bank branches:
- Predict daily customer arrivals
- Optimize teller staffing
- Reduce wait times
- Improve operational efficiency

## 📈 Regression Model Results

| Statistic | Value |
|-----------|-------|
| **Multiple R** | 0.848 |
| **R Square** | **0.719** (72% variance explained) |
| **Adjusted R Square** | 0.711 |
| **F-statistic** | **90.07** |
| **Significance F** | 3.08E-64 (highly significant!) |
| **Observations** | 254 |

## 🔍 Key Findings — Day of Week Impact

Compared to Friday (baseline):
- **Monday:** 211 fewer customers
- **Tuesday:** 461 fewer customers (quietest day)
- **Wednesday:** 479 fewer customers
- **Thursday:** 440 fewer customers
- **Friday:** Highest activity (baseline)

## 🎉 Special Events Impact

- **Staff Paydays:** +369 more customers
- **Faculty Paydays:** +369 more customers
- **Holidays (nearby):** +281 more customers

## 🌳 Decision Tree Analysis

![Decision Tree](02-decision-tree-analysis.png)

Expected Value calculation for **Project 1**:
- Multi-path decision tree
- Probability calculations at each node
- Payoff outcomes: -$2,500 to +$3,000
- **Final Expected Value: -$25**

## 💡 Business Recommendations

### More Tellers Needed:
- **Mondays** — Surprisingly busy
- **Staff Paydays** — +369 customer surge
- **Faculty Paydays** — +369 customer surge

### Fewer Tellers Needed:
- **Around Holidays** — Fewer arrivals
- **Wednesdays & Thursdays** — Slowest days
- **Reduce idle teller time**
